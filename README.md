# Gemini Guided Breadcrumbs 🚀

Welcome to my frontend development repository! This project is a hands-on learning laboratory dedicated to mastering semantic HTML structures and custom CSS layouts for webpage **breadcrumb navigation**.

## 🧠 Learning Methodology
Unlike traditional tutorials, this project is built using **Gemini Guided Learning**. I am working alongside an AI technical mentor in a collaborative, investigative dialogue. Instead of copying pre-written code snippets, I am exploring the fundamental layout principles, debugging my own implementations, and building the styles from scratch.

## 🛠️ Skills Tracked
* **Semantic Web Architecture:** Crafting accessible navigation links.
* **CSS Layout Mechanics:** Aligning items horizontally and styling interactive elements.
* **Version Control & Git CLI:** Managing branches, commits, and remote repositories using the terminal (macOS / Termux).

## 📂 Project Structure
* `index.html` — The core markup skeleton for the breadcrumb trails.
* `styles.css` — Custom stylesheet exploring layout properties.
