2. Interactive Knowledge Verification

Concept 1: Core Layout Mechanics

Why did applying display: inline-block to the parent container .breadcrumb fail to line the links up horizontally, whereas applying it to .breadcrumb li worked instantly?

Applying styles to the parent container modifications behaves on the entire wrapper boundary relative to the webpage layout. The child list items (<li>) inherently maintain their user-agent default display: list-item properties. To alter block stacking, you must explicitly target the concrete child elements occupying structural lines.

Concept 2: The Stubborn Anchor Underline

Why does targeting the li text decoration properties fail to remove browser link colors and lines?

The standard browser user-agent stylesheet injects explicit, prioritized decoration guidelines directly onto the <a> tags. Because native default styles on anchor tags resist implicit inherited values from broad container targets, you must pass structural adjustments directly to the .breadcrumb a selector explicitly.

Concept 3: Dynamic Attribute Selectors

Explain how li[aria-current="page"] isolates the active user page from general history items without manually modifying structural CSS class names.

The syntax leverages CSS Attribute Selection. By mapping targeted designs directly to DOM properties (aria-current), styles update dynamically alongside accessibility indicators. This decouples formatting logic from custom class boilerplate.

3. Production Style Blueprints

Review the comprehensive stylesheet implementation built throughout our guided lesson:

/* 1. Global Reset Constraints */
.breadcrumb {
    list-style: none;
    padding: 0;
    margin: 0;
}

/* 2. Horizontal Flow Vector */
.breadcrumb li {
    display: inline-block;
}

/* 3. Non-Destructive Separation Injection */
.breadcrumb li:not(:first-child)::before {
    content: "/";
    padding: 0 8px;
    color: #ccc;
}

/* 4. Anchor State Controls */
.breadcrumb a {
    text-decoration: none;
    color: #333;
}

.breadcrumb a:hover {
    color: #0066cc;
    text-decoration: underline;
}

/* 5. Static Context Delineation */
.breadcrumb li[aria-current="page"] {
    color: #777777;
    font-weight: bold;
}
